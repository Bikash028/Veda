# 📊 Day 8 – Retail Sales Tracker

## 📌 Project Overview

This project is a Retail Sales Tracker created using Google Sheets.

The objective is to analyze retail transaction data and create an
automated summary of sales performance at daily, weekly, and monthly
levels.

The project uses spreadsheet formulas, date-based calculations,
SUMIFS, data validation, and manual verification to create a simple
and reusable sales tracking system.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze retail sales transaction data.
- Calculate total sales and quantity.
- Calculate the number of transactions.
- Calculate average transaction value.
- Calculate daily sales.
- Calculate weekly sales using SUMIFS.
- Calculate monthly sales using SUMIFS.
- Use date ranges for sales rollups.
- Apply data validation to reduce incorrect entries.
- Perform manual checks to verify calculated results.

---

## 🗂️ Dataset

The project uses a Retail Sales Dataset containing 1,000 transactions.

Important fields include:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

The `Total Amount` column is treated as the sales value used for the
sales calculations.
