# Day 2 - OTT Streaming Content Trend Analysis

## Objective
Analyze Netflix content trends to understand genre popularity, ratings, release patterns, regional distribution, and content duration.

## Work Completed
- Analyzed genre popularity
- Compared Movies and TV Shows by genre
- Analyzed content ratings
- Studied country-wise content distribution
- Analyzed release trends
- Analyzed content added to Netflix over time
- Compared movie duration and TV show seasons
- Performed SQL aggregations for key content metrics
- Created more than 6 visualizations
- Prepared 3 actionable content strategy insights

## Key Insights
- International Movies, Dramas, and Comedies are among the largest content categories.
- TV-MA and TV-14 dominate the Netflix catalog.
- TV Show releases increased strongly in recent years.
- Netflix has content associated with 127 countries, showing strong global coverage.
