# 📊 Excel Data Analysis – Superstore Dataset

## 📌 Project Overview

This project focuses on analyzing the Sample Superstore dataset using
Microsoft Excel.

The objective is to transform raw sales data into useful business
information using Excel formulas, sorting, filtering, PivotTables, and
summary analysis.

The analysis focuses on sales, profit, quantity, categories, regions,
and product sub-categories.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze sales and profit performance.
- Calculate important business KPIs.
- Use Excel formulas for conditional analysis.
- Analyze sales by product category and region.
- Analyze profit by category and sub-category.
- Create PivotTables to summarize the dataset.
- Identify important business findings.
- Present the results in a clear Summary sheet.

---

## 🗂️ Dataset

The project uses the **Sample Superstore dataset**.

Important fields include:

- Ship Mode
- Segment
- Country
- City

- Category
- Sub-Category
