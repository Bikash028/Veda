# Day 15 – Product Count Analysis

## Overview
As part of my Data Analytics Internship, Day 15 focused on performing Product Count Analysis using Microsoft Excel and the Sample Superstore dataset.
The objective was to count records by product category, identify the category with the highest number of records, and practice using COUNTIF and COUNTIFS functions.

## Objectives

- Count records for each product category.
- Compare product/category counts.
- Identify the category with the highest number of records.
- Practice COUNTIF for single-condition analysis.
- Practice COUNTIFS for multiple-condition analysis.

## Dataset
The analysis was performed using the Sample Superstore dataset.
### Dataset Details
- Total Records: 9,994
- Total Columns: 19
- Category Column: Category
- Region Column: Region

The main categories analyzed were:
- Furniture
- Office Supplies
- Technology
